# WeldSight — отчёт по этапу 1 (для оформления документа)

## 1. Постановка

Сегментация дефектов сварных швов на рентгенограммах (НК) с оценкой неуверенности модели.
Исследовательский вопрос (этапы 2–3): повышают ли дефекты, сгенерированные диффузионной
inpainting-моделью, recall по редким классам по сравнению с обучением (а) без аугментации дефектов и
(б) с copy-paste аугментацией. Оценка проводится только на реальных снимках.

**Использованный датасет (этап 1): RIAWELC.** Причины: только его удалось скачать из среды
разработки (Dropbox и Google Drive там заблокированы), и только в нём есть несколько классов с
заметным объёмом. Код поддерживает все три датасета: адаптеры `riawelc`, `gdxray`, `swrd`.

**Рекомендация для основной работы — SWRD.** Только в нём есть многоклассовые полигоны, из которых
получаются маски для сегментации (IoU) и для inpainting. Лицензию нужно подтвердить у авторов.

## 3. Что обнаружено в данных (важно для текста работы)

1. **Официальное разбиение RIAWELC протекает.** 108 из 109 исходных снимков встречаются и в
   training, и в testing. 2 443 файла — байт-в-байт копии в разных сплитах (включая 30 файлов
   «… - Copia.png»). Точность, посчитанная на этом разбиении, измеряет запоминание снимков.
2. **Имена файлов кодируют источник** (`RRT-26R_Img2_...` = образец шва RRT-26R, плёнка Img2).
   Всего 29 образцов и 109 снимков. Серия RRT — это BAM Round Robin Test, тот же источник, что у
   GDXray W0003.
3. Соответствие папок классам проверено по числам из статьи и визуально: Difetto1 = трещина
   (7 635), Difetto2 = пористость (6 320), Difetto4 = непровар (4 452), NoDifetto = без дефекта
   (6 000). Размер патчей 227×227, а не 224×224, как написано в README.
4. **Смещение отбора.** Патчи «без дефекта» почти однородные (медианное СКО яркости 7 против ≈25
   у дефектных). Одно СКО отделяет «дефект / не дефект» с AUROC 0,91. Поэтому метрика
   «дефект / не дефект» на RIAWELC неинформативна.
5. **Малая эффективная выборка.** 21 964 уникальных патча, но только 29 образцов. Непровар есть
   в 10 образцах, трещины — в 13. В тестовой части на класс приходится 2–4 образца.

Что сделано с данными: дубликаты удалены, данные заново разбиты **по образцам шва** (все
снимки одного образца попадают в один сплит) в пропорции 70/15/15 со стратификацией по классам.
Получилось: train — 17 образцов (15 560 патчей), val — 6 (3 331), test — 6 (3 073).
Патчи приведены к 256×256.

## 4. Модель

- **Архитектура:** U-Net из библиотеки `segmentation_models_pytorch` (smp 0.5.0) с энкодером ResNet.
  По умолчанию ResNet-34 с весами ImageNet; в прогоне этапа 1 — ResNet-18 без предобучения
  (см. ограничения). Вход — 1 канал, 256×256.
- **Выходы:** (1) карта сегментации K+1 классов (softmax); (2) многометочная голова классификации
  патча (aux head smp).
- **Функция потерь:** Dice + Focal для сегментации (на патчах с масками) + focal BCE для головы
  патча. RIAWELC масок не содержит, поэтому в прогоне этапа 1 обучалась только голова патча.
- **Неуверенность:** MC Dropout. Dropout стоит на bottleneck, перед сегментационной головой и в
  голове классификации. На тесте dropout включён, BatchNorm остаётся в режиме eval, T = 10–20
  проходов. Меры: предсказательная энтропия, ожидаемая энтропия, взаимная информация (BALD).
- **Обучение:** AdamW (lr 3e-4, wd 1e-4), warmup + косинусное расписание, AMP на GPU, ранняя
  остановка по val macro-F1. Базовые аугментации: отражения, яркость, контраст, гамма.

## 5. Метрики

- По каждому классу: recall (с 95 % доверительным интервалом по кластерному бутстрепу снимков),
  precision, F1, AUROC, AP. Для датасетов с масками добавляются IoU, пиксельный recall и recall
  по отдельным дефектам (компонентам связности).
- Кривая «recall против доли снимков, отправленных инспектору». Снимки ранжируются по
  неуверенности MC Dropout (максимум по патчам снимка). Верхние f % отправляются инспектору; он
  считается безошибочным, так что кривая — оптимистичная оценка сверху. Для сравнения строятся
  кривые случайного отбора и оракула.

## 6. Результаты этапа 1 (RIAWELC, тест из 6 новых образцов, только реальные снимки)

Конфигурация прогона: ResNet-18 без предобучения, 8 000 патчей train, CPU, 9 эпох (лучшая — 5-я),
seed 42, git e3dc84c, версия данных 2c33eedecb1697b9.

| Класс | Recall, % (95 % ДИ) | Precision, % | F1 | AUROC |
|---|---|---|---|---|
| Трещина | 57,0 (52,6–66,7) | 67,0 | 0,62 | 0,86 |
| Пористость | 93,1 (86,8–97,2) | 93,5 | 0,93 | 0,99 |
| Непровар | 19,0 (2,3–42,8) | 64,4 | 0,29 | 0,72 |
| Среднее (macro) | 56,4 | 75,0 | 0,61 | 0,86 |

| Доля снимков у инспектора | Recall модели, % | Случайный отбор, % | Оракул, % |
|---|---|---|---|
| 0 % | 60,4 | 60,4 | 60,4 |
| 10 % | 65,4 | 64,1 | 69,0 |
| 20 % | 71,2 | 67,9 | 75,9 |
| 30 % | 76,8 | 71,5 | 81,5 |

Как хорошо неуверенность указывает на ошибки (AUROC): предсказательная энтропия — 0,82,
взаимная информация — 0,54.

**Интерпретация:**
- Пористость распознаётся надёжно. Трещины — посредственно. Непровар на тесте почти не
  распознаётся, хотя на валидации его recall был 0,79. Это разброс между образцами швов, а не
  переобучение в обычном смысле; одно разбиение с 2–4 образцами на класс его не выявит.
- Взаимная информация (эпистемическая часть) почти не несёт сигнала об ошибках, а полная
  предсказательная энтропия несёт. Выбирать меру неуверенности нужно на валидации, а не на тесте.

## 7. Ограничения

- Прогон этапа 1 сделан на CPU без интернета, поэтому энкодер не предобучен, а train взят не
  целиком. Полный прогон на GPU: `notebooks/02_train_gpu.ipynb`, конфигурация
  `configs/experiment/riawelc_baseline.yaml`.
- На RIAWELC нет масок, поэтому IoU не считается. Для сегментации и этапа 3 (inpainting)
  нужен SWRD.
- Кривая направления инспектору предполагает идеального инспектора.
